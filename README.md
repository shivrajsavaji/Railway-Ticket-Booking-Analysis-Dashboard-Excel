# Railway Ticket Booking Analysis Dashboard | Excel

## 📌 Project Overview

This project focuses on analyzing railway ticket booking data using Microsoft Excel. The dashboard provides insights into passenger booking patterns, travel distances, and ticket confirmation status.

The main objective is to transform raw booking data into meaningful insights through data analysis, Pivot Tables, and charts.

## 🎯 Project Objectives

- Analyze railway ticket booking records.
- Understand passenger booking patterns and travel distances.
- Analyze confirmed, RAC, and waitlisted ticket statuses.
- Summarize data using Pivot Tables.
- Present key metrics and trends through an Excel dashboard.

## 📊 Dataset Information

- **Total Records:** 30,000+
- **Total Columns:** 21
- **Domain:** Railway Ticket Booking
- **Tool Used:** Microsoft Excel

The dataset contains railway booking information used to analyze passenger details, travel patterns, and reservation status.

## 🛠️ Tools and Techniques

- **Microsoft Excel:** Data analysis and dashboard creation
- **Pivot Tables:** Summarizing and grouping booking data
- **Excel Charts:** Visualizing booking patterns and trends
- **Data Analysis:** Identifying patterns in booking records
- **Dashboard Design:** Presenting key metrics in a visual format

## 📈 Key Analysis

The dashboard focuses on the following areas:

- Passenger booking statistics
- Travel distance analysis
- Ticket confirmation status
- RAC and waitlisted ticket analysis
- Booking trends and patterns
